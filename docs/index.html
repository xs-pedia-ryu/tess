QRIS PAYMENT GATEWAY

API Documentation

← Kembali ke Web

API ini dibuat untuk menghubungkan website kedua kamu ke gateway QRIS. Base URL publik adalah https://xspedia-payment.vercel.app. Backend project tetap menggunakan GoBiz untuk membuat dan mengecek pembayaran. QRIS dibuat dengan masa aktif tetap 15 menit.

Base URL: https://xspedia-payment.vercel.app
Gunakan endpoint /api/v1/* untuk integrasi API. Tidak memerlukan API key. Status dan cancel cukup menggunakan paymentId. Tidak ada paymentToken pada API publik.

Backend: tetap memakai GoBiz. Domain API hanya alamat gateway.

ID transaksi: halaman web menghasilkan xiao-web-123456, sedangkan request API menghasilkan xiao-api-123456.
POST/api/paymentsWEB

Request

Dipakai oleh halaman web gateway. Tidak membutuhkan API key. ID akan dibuat dengan format xiao-web-123456.

curl -X POST "https://xspedia-payment.vercel.app/api/payments" \ -H "Content-Type: application/json" \ -d '{"amount":50000}'

Response 201

{ "success": true, "data": { "paymentId": "xiao-web-274819", "amount": 50000, "status": "pending", "createdAt": 1788058800000, "expiresAt": 1788059700000, "expiresInMs": 900000, "qr": "data:image/png;base64,...", "qrisString": "000201..." } }
POST/api/v1/payments

Request

Gunakan nominal dalam Rupiah. Tidak memerlukan API key. Server otomatis menetapkan expired 15 menit.

curl -X POST "https://xspedia-payment.vercel.app/api/v1/payments" \\ -H "Content-Type: application/json" \\ -d '{"amount":50000}'

Response 201

{ "success": true, "data": { "paymentId": "xiao-api-483921", "amount": 50000, "status": "pending", "createdAt": 1788058800000, "expiresAt": 1788059700000, "expiresInMs": 900000, "qr": "data:image/png;base64,...", "qrisString": "000201..." } }
POST/api/v1/payments/{paymentId}/status

Request

Tidak memerlukan API key dan tidak menggunakan paymentToken. Cukup gunakan paymentId pada URL. Gateway langsung melakukan live-check ke GoBiz.

curl -X POST "https://xspedia-payment.vercel.app/api/v1/payments/xiao-api-483921/status" \\n -H "Content-Type: application/json" \\n -d '{}'

Response 200

{ "success": true, "data": { "id": "xiao-api-483921", "amount": 50000, "status": "paid", "createdAt": 1788058800000, "expiresAt": 1788059700000, "paidAt": 1788058865000, "transactionId": "TX-123456" } }
GET/api/v1/payments/history

Request

Mengambil riwayat pembayaran terbaru. Tidak memerlukan API key. Default 50 item, maksimal 100.

curl "https://xspedia-payment.vercel.app/api/v1/payments/history?limit=50"

Response 200

{ "success": true, "data": [ { "id": "xiao-api-483921", "amount": 50000, "status": "paid", "createdAt": 1788058800000, "expiresAt": 1788059700000, "paidAt": 1788058865000, "transactionId": "TX-123456", "source": "api" } ] }
POST/api/v1/payments/{paymentId}/cancel

Request

Membatalkan sesi QR yang masih berstatus pending. Tidak memerlukan API key dan tidak menggunakan paymentToken. Cukup gunakan paymentId.

curl -X POST "https://xspedia-payment.vercel.app/api/v1/payments/xiao-api-483921/cancel" \\n -H "Content-Type: application/json" \\n -d '{}'

Response 200

{ "success": true, "data": { "id": "xiao-api-483921", "amount": 50000, "status": "cancelled", "cancelledAt": 1788058900000 } }
GET/api/health

Response

{ "ok": true, "service": "gobiz-qris-web-gateway", "time": "2026-09-29T03:00:00.000Z" }

Status pembayaran

StatusArti
pendingQR aktif, menunggu pembayaran.
paidPembayaran terdeteksi di transaksi GoBiz.
expiredLewat 15 menit dan belum terbayar.
cancelledSesi QR dibatalkan melalui endpoint cancel.
Catatan cancel: endpoint cancel membatalkan sesi gateway. Kode ini tidak mengklaim membatalkan transaksi GoBiz yang sudah berhasil/settlement karena modul yang disertakan tidak menyediakan endpoint pembatalan transaksi tersebut.
API publik tidak memerlukan API key maupun paymentToken. Status/cancel cukup menggunakan paymentId. QRIS yang sudah expired harus dibuat ulang. Backend gateway tetap memakai GoBiz.
